# Trading Signal Platform

AI-powered trading signal platform med paper trading journal.

## Windows Quick Start

1. Se till att Python och Node.js ar installerade
2. `copy .env.example .env` och lagg till din Anthropic API key (valfritt)
3. Dubbelklicka pa `start.bat`
4. Oppna http://localhost:5173

## Tidsramar
- **15min** - Scalping
- **day** - Day trading
- **swing** - 2-10 dagars innehav
